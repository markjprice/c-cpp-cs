- `nanopb/nanopb` is a small Protocol Buffers implementation in C. It’s good because it’s real-world but compact that shows structured C code and so it’s a good introduction to C libraries: https://github.com/nanopb/nanopb
- `antirez/linenoise` is a very small codebase for a weal-world utility (command-line editing) so it’s easy to read in one sitting: https://github.com/antirez/linenoise
- `oz123/awesome-c` is a curated list of C libraries and tools so it will let you explore based on your interests: https://github.com/oz123/awesome-c
